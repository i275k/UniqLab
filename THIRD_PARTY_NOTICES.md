### Qt, PySide6 and Shiboken6 (LGPL-3.0)

UniqLab uses Qt through PySide6 under the GNU Lesser General Public License
version 3 (`licenses/LGPL-3.0.txt`, which supplements `licenses/GPL-3.0.txt`).
Qt is used unmodified and is linked dynamically: the packages are PyInstaller
"one-folder" builds, so the Qt and PySide6 shared libraries are separate files
that you may replace with your own compatible builds:

* macOS: `UniqLab.app/Contents/Frameworks/PySide6/`
* Windows: `<install folder>\_internal\PySide6\`
* Linux AppImage: extract with `--appimage-extract`, then `squashfs-root/usr/lib/UniqLab/_internal/PySide6/`

The corresponding Qt and PySide6 source code is available from the links in the
table above (tag `v6.11.3`). Qt includes further third-party components
(for example FreeType, HarfBuzz, libpng, zlib, PCRE2, double-conversion, md4c),
each under a permissive license. Their copyright notices and license texts are
in `licenses/Qt-third-party-notices.txt`, generated by `tools/make_qt_notices.py`
from the official `qtbase-everywhere-src-6.11.3` source archive (see also
https://doc.qt.io/qt-6/licenses-used-in-qt.html).

### Python runtime and OpenSSL

The packages contain the CPython 3.12 runtime of the build machine
(`licenses/Python-LICENSE.txt`, copied at build time; it also covers libffi,
zlib, libmpdec and expat). Python's `ssl` module links OpenSSL 3, which is
licensed under the Apache License 2.0 (`licenses/Apache-2.0.txt`). The `bz2`
module includes bzip2 (`licenses/bzip2-LICENSE.txt`); the `lzma` module uses
liblzma from XZ Utils (0BSD/public domain).

### Pillow

## Downloaded on request, not redistributed

UniqLab does **not** include FFmpeg, FFprobe or ExifTool. When the user clicks
“Download & Install All” in Settings → Components, the app downloads pinned,
official builds directly from their publishers into the user's own data folder
(`~/Library/Application Support/UniqLab`, `%LOCALAPPDATA%\UniqLab`,
`$XDG_DATA_HOME/UniqLab`) and verifies each archive against a SHA-256 checksum
before use. The user can also point UniqLab to copies installed by other means.
